# 📰 **trader-news**

*Tracks breaking headlines and SEC filings on every stock you watch, flagging market-moving catalysts before setups become trades.*

![Python](https://img.shields.io/badge/python-3.x-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## 📰 What It Does

A chart setup can look technically perfect and still collapse on an unannounced earnings report, trading halt, or material SEC filing. `trader-news` monitors Yahoo Finance headlines and SEC EDGAR 8-K filings for every stock on your watchlist, planned trade, or open portfolio, reporting only new events in Eastern Time (ET). It pairs categorized news items with intraday percentage moves against yesterday's close, ensuring you never enter a setup blind to breaking catalysts.

## 🚀 Quick Start

```bash
# Check watchlist, active plan, and portfolio tickers for fresh news
python3 news.py

# Monitor specific tickers over a custom lookback window (e.g., 12 hours)
python3 news.py --tickers TSLA NVDA AMD --hours 12

# Inspect all items from the past 72 hours, including previously seen items
python3 news.py --tickers TSLA --all --hours 72

# Output machine-readable JSON without fetching SEC filings
python3 news.py --no-sec --json

# Run a dry check without updating the persistent state cache
python3 news.py --dry-run
```

## 📂 What It Reads & Writes

| File | Purpose |
| --- | --- |
| `--tickers` or `trader/watchlist.json` | Scanner hits generated by `trader-scanner` |
| `trader/plan.json` | Planned trade setup created by `trader-exit` |
| `trader/portfolio.json` | Current held positions recorded by `trader-broker` |
| Yahoo Finance RSS Feed | Real-time news headlines per ticker |
| Yahoo Finance Chart Endpoint | Last price vs. yesterday's close to detect momentum |
| SEC EDGAR Atom Feed | Company 8-K (and 10-Q) filings; requires `sec_user_agent` in `trader/config.json` or `SEC_USER_AGENT` |
| `trader/state/news.json` | 30-day cache of seen items and ticker CIK mappings |

## 📋 Operating Rules

- **Headlines are leads, not facts:** Open and read the original story or filing before acting. Quote sources, provide direct links, and explicitly note paywalled articles.
- **Filings beat headlines:** If an 8-K filing contradicts media reporting, the company's official SEC disclosure takes precedence.
- **Tag what it touches:** Every item lists impacted tickers and category tags (`earnings`, `analyst`, `legal`, `deal`, `capital`, `people`, `risk`, `halt`, `regulatory`, `macro`).
- **Critical filings (`!`):** Flagged when an 8-K includes material events:
  - `1.03` Bankruptcy
  - `1.05` Cybersecurity incident
  - `2.02` Earnings results
  - `2.04` Debt acceleration
  - `2.06` Material impairment
  - `3.01` Delisting notice
  - `4.02` Non-reliance on previously issued financials
  - `5.01` Change in control
  - `5.02` Director or officer departure/appointment
- **MOVING alert:** Flags stocks moving 3% or more (`--move-pct`) from yesterday's close.
- **Zero predictions:** Reports published facts and price deviation from yesterday's close without forecasting future price movement.

## 🛡️ Guardrails & Safety

- **No fabrication:** Never invents or embellishes headlines, quotes, or metrics.
- **No autonomous trading:** Never trades on news or recommends buying or selling based on headlines.
- **Respectful rate limiting:** Emits one request per feed per ticker with polite pacing, staying well below SEC limits (10 req/sec).
- **Tooling, not financial advice:** Operates solely in an informational capacity. Orders are never placed except via `/trader-broker` after `/trader-risk` passes and the user provides an explicit confirmation.
